# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание
Проект представляет собой учебную версию сайта интернет-магазина, разработанную с использованием фреймворка Bootstrap 5.

## Используемые технологии
- HTML5;
- Bootstrap 5 (подключение через CDN);
- CSS (файл `css/custom.css` для минимальных правок);
- Git, GitHub.

## Структура проекта
- `index.html` — главная страница (Hero, Преимущества, Популярные товары);
- `catalog.html` — каталог товаров (Сетка карточек, модальное окно);
- `product.html` — страница подробного описания товара (Хлебные крошки, таблица, аккордеон);
- `order.html` — страница с формой заявки;
- `css/custom.css` — дополнительные стили;
- `README.md` — описание проекта.

## Реализованные Bootstrap-компоненты (ПЗ 10)
В проекте использованы следующие компоненты и классы Bootstrap:
- **Сетка:** `container`, `row`, `col-12`, `col-md-6`, `col-lg-4`, `g-4`.
- **Навигация:** `navbar`, `navbar-expand-lg`, `collapse`.
- **Карточки:** `card`, `card-img-top`, `card-body`.
- **Кнопки:** `btn`, `btn-primary`, `btn-outline-primary`.
- **Значки:** `badge`.
- **Сообщения:** `alert`.
- **Модальное окно:** `modal` (на странице каталога).
- **Формы:** `form-control`, `form-select`, `input-group`, `form-check` (на странице заявки и в модальном окне).
- **Дополнительный компонент:** `accordion` (на странице товара).
