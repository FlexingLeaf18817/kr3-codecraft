# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание проекта
Образовательный IT-портал «CodeCraft». Проект представляет собой адаптивную версию сайта онлайн-школы, разработанную на чистом HTML и CSS без использования сторонних фреймворков (в отличие от версии КР №2 на Bootstrap). 

## Ссылка на опубликованный проект
GitHub Pages: [https://flexingleaf18817.github.io/kr3-codecraft/](https://flexingleaf18817.github.io/kr3-codecraft/)

## Структура проекта
- `index.html` — Главная страница (промо-блок, преимущества, популярные курсы);
- `courses.html` — Каталог курсов (сетка направлений, фильтры);
- `course-detail.html` — Детальная страница курса (учебный план, аккордеон);
- `teachers.html` — Преподаватели (карточки с заглушками вместо фото);
- `blog.html` — Блог (сетка статей);
- `article.html` — Страница статьи (лонгрид, типографика);
- `css/style.css` — основной файл стилей.

## Используемые технологии
- HTML5 (семантическая разметка);
- CSS3 (Flexbox, CSS Grid, CSS-переменные, методология БЭМ);
- Адаптивная вёрстка (медиазапросы);
- Доступность интерфейса (a11y).

## Адаптивные решения (КР3)
- Резиновая сетка карточек реализована через CSS Grid (`repeat(auto-fill, minmax(300px, 1fr))`);
- Для экранов меньше 768px написан медиазапрос (`@media (max-width: 768px)`), который перестраивает сетки в один столбец;
- Шапка сайта (навигация) на мобильных устройствах перестраивается вертикально с помощью `flex-direction: column`;
- Изображения и заглушки корректно масштабируются и не выходят за пределы карточек.

## Доступность интерфейса (a11y)
- Для всех интерактивных элементов (ссылки, кнопки, поля форм, аккордеон) добавлен видимый фокус через псевдокласс `:focus-visible` (синяя обводка);
- Соблюдена семантическая структура: используются теги `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`;
- У изображений заданы атрибуты `alt`;
- Цветовой контраст текста и фона проверен и соответствует базовым требованиям;
- Вместо фотографий реальных людей используются безопасные текстовые заглушки (серые блоки с инициалами), реализованные на CSS.
