# CodeCraft — Образовательный IT-портал

## Контрольная работа №3
Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание проекта
Многостраничный адаптивный сайт онлайн-школы программирования «CodeCraft». 
Проект реализован на чистом HTML и CSS без использования фреймворков (в отличие от КР №2, где использовался Bootstrap).

## Структура проекта
- `index.html` — Главная страница;
- `courses.html` — Каталог курсов;
- `course-detail.html` — Страница конкретного курса;
- `teachers.html` — Преподаватели;
- `blog.html` — Блог (база знаний);
- `article.html` — Страница статьи;
- `css/style.css` — Основной файл стилей.

## Реализованная адаптивность
- Сетки карточек реализованы через `CSS Grid` (`repeat(auto-fill, minmax(300px, 1fr))`);
- Шапка сайта и внутренние элементы карточек выстроены через `Flexbox`;
- Написаны медиазапросы (`@media (max-width: 768px)`) для перестройки сеток в один столбец и адаптации навигации на мобильных устройствах.

## Реализованная доступность (a11y)
- Семантическая разметка (использование `header`, `nav`, `main`, `article`, `footer`);
- Наличие видимого фокуса (`:focus-visible`) для навигации с клавиатуры;
- Атрибуты `alt` для всех изображений;
- Корректная иерархия заголовков.
